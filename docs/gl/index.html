Un pequeno espazo para a música

Pentagrama nace dunha necesidade sinxela: imprimir papel pautado flexible, rápido e sen publicidade na folla. Feito para poder escribir música con liberdade.

O proxecto é de balde e segue a filosofía Value for Value: se che resulta útil e queres apoialo, podes facer unha microdoazón voluntaria por Lightning. Recomendalo tamén axuda.
