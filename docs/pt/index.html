Um pequeno espaço para a música

O Pentagrama nasceu de uma necessidade simples: papel de música flexível, rápido de imprimir e sem publicidade na folha. Para escrever música com liberdade.

O projeto é gratuito e segue a filosofia Value for Value: se te for útil, podes apoiar com um microdonativo voluntário por Lightning. Recomendá-lo também ajuda.

Copia este endereço para a tua carteira Lightning.

Privacidade e estatísticas

Contamos visitas e ações de imprimir, aplicar, guardar e partilhar modelos para perceber o que vos é útil e melhorar o Pentagrama.

Usamos o Umami, sem cookies de rastreamento nem envio de nomes, conteúdos ou códigos de configuração dos modelos. Podes excluir este navegador quando quiseres.

O teu navegador pediu para não ser rastreado. Respeitamos esta preferência mesmo com este interruptor desativado.
